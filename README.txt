Nomi GitHub Version 2.1.5

This ZIP contains all files for the GitHub Pages version.

What changed:
- The mail subject is now: "Nomi – Atemmeditation für mehr Ruhe im Alltag".
- The mail body now says: "Du kannst Nomi direkt im Browser nutzen:" and no longer uses the label "Als Webseite:".
- The Settings view has been softened visually:
  - The start screen remains visible behind a translucent, blurred background.
  - The settings card now behaves more like a calm settings panel/sheet.
  - The panel has softer edges, less hard contrast and a gentle entrance animation.
  - The panel is centered on larger screens and sits like a bottom sheet on smaller screens.
- Existing meditation interaction, pause/resume sound handling, progress bar, themes and animation styles remain unchanged.
- All visible app controls remain in English.

Important:
This ZIP does not include MP3 files so your existing sounds on GitHub are not overwritten.
Keep these files unchanged:

- ausatmen.mp3
- ende.mp3
