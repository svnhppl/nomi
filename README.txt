Nomi GitHub Version 2.0.6

This ZIP is for the GitHub Pages version only.

What changed:
- Settings now include a Geometry option for the animated graphic.
- Two geometry options are available:
  - Petals: the current leaf-like Nomi animation.
  - Orbs: a rounder animation built from circular elements.
- The selected geometry is saved with the other user settings.
- The three color themes still apply to both geometries.
- The mobile Settings width fixes from v2.0.5 remain in place.
- The Breathing Rhythm choices remain unchanged.
- iPhone audio handling remains unchanged.
- Fallback tones remain removed.

Important:
This ZIP does not include MP3 files so your existing sounds on GitHub are not overwritten.
Keep these files unchanged:
- einatmen.mp3
- ausatmen.mp3
- ende.mp3

Upload all files from this ZIP into the GitHub repository root and overwrite existing files where GitHub asks.
